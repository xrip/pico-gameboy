# Инструменты pico-gameboy

[English version](README.md)

## make_gbbp.py — создание подложки

Делает из любой картинки файл подложки (бэкплана, `.gbbp`) для pico-gameboy.

### Требования

Python 3, только стандартная библиотека. PNG (все типы цвета и разрядности, включая interlaced), GIF (первый кадр), BMP (1/4/8/16/24/32 бит, без сжатия) и PNM (PBM/PGM/PPM) скрипт декодирует сам. Остальные форматы (JPEG, WebP, ...) читаются через Pillow, если он установлен (`pip install pillow`).

### Запуск

```
python3 make_gbbp.py picture.png [опции]
```

| Опция | По умолчанию | Значение |
|---|---|---|
| `-o`, `--output FILE` | имя картинки с `.gbbp` | выходной файл |
| `--scale-x K` | 1 | ячеек на пиксель картинки по горизонтали |
| `--scale-y K` | 1 | ячеек на пиксель картинки по вертикали |
| `--shift-x N` | 0 | левый край части TV-SOFT в отмасштабированной картинке |
| `--shift-y N` | 0 | верхний край в отмасштабированной картинке |
| `--scale-x3`, `--scale-y3` | вычисляется | переопределить масштаб для 3x |
| `--shift-x3`, `--shift-y3` | вычисляется | переопределить смещение для 3x |
| `--dither` | выкл. | дизеринг Флойда–Стейнберга вместо ближайшего цвета |
| `--fill RRGGBB` | `000000` | цвет за пределами картинки и под её прозрачными местами |
| `--preview FILE.png` | — | PNG со всеми четырьмя подложками, игровое окно показано серым |

### Геометрия

Подложка состоит из ячеек. Ячейка — это 2x2 пикселя экрана 640x480; на TV одна строка поля — один ряд ячеек. При масштабе 1 один пиксель картинки попадает в одну ячейку.

- **TV-SOFT**: 384x240 ячеек, вырезается из отмасштабированной картинки с точки (`shift-x`, `shift-y`).
- **HDMI/VGA**: 320x240 ячеек, вырезается из того же места, но на 32 ячейки правее, поэтому картинка в обоих случаях стоит на экране в одном и том же месте. Смещение TV-SOFT 0:0 означает, что HDMI/VGA само начинается с 32:0.

Смещение задаётся в координатах отмасштабированной картинки, то есть применяется после масштаба.

У каждой части по два варианта, по одному на каждое игровое окно:

| Экран | Игровое окно (ячейки): x, y, w, h |
|---|---|
| 2x | по центру, 48, 160, 144 |
| 3x | по центру, 12, 240, 216 |

`--scale-*` и `--shift-*` задают вариант 2x, а 3x вычисляется из них. Окно 3x в 1.5 раза больше, поэтому картинка масштабируется ещё в 1.5 раза вокруг центра окна (ячейка 192,120 части TV-SOFT), и то, что было под окном 2x, остаётся под окном 3x:

```
scale-x3 = 1.5 * scale-x
scale-y3 = 1.5 * scale-y
shift-x3 = (shift-x + 192) * 1.5 - 192
shift-y3 = (shift-y + 120) * 1.5 - 120
```

Вычисленные значения выводятся в консоль. Опции `--*3` переопределяют их, и тогда в консоли видны оба значения, например `3x shift-y3: computed 150.61, override 152 applied`.

Масштаб по осям может отличаться, например чтобы область LCD на картинке точно совпала с игровым окном.

### Цвета

Каждая часть (HDMI/VGA, TV-SOFT) получает 32 цвета, подобранных k-means по обоим её вариантам. Каждая ячейка берёт ближайший из них. С `--dither` ошибка вместо этого разносится по соседям, ценой шума на плавных градиентах.

### Примеры

```
# картинка как есть, левый верхний угол в TV-SOFT 0:0
python3 make_gbbp.py picture.png

# картинка консоли: рамка LCD точно под окном 2x, с превью
python3 make_gbbp.py green.png --scale-x 0.51282 --scale-y 0.53933 --shift-x 39.282 --shift-y 60.404 --preview p.png

# то же, но за пределами картинки белый вместо чёрного
python3 make_gbbp.py green.png --scale-x 0.51282 --scale-y 0.53933 --shift-x 39.282 --shift-y 60.404 --fill ffffff -o green-white.gbbp
```

Результат удобно проверять через `--preview`. Сверху вниз там идут: HDMI/VGA 2x, HDMI/VGA 3x, TV-SOFT 2x, TV-SOFT 3x.

### Установка на консоль

1. Скопировать `.gbbp` на SD-карту (готовые лежат в `sd-card/GB`).
2. Выбрать его в файловом менеджере эмулятора. Появится сообщение `Backplan is installed` или, если у файла другая версия или размер, `This backplan version is unsupported`.
3. Файл копируется в `/.config/gbc/backplane.gbbp` и дальше используется вместо встроенной подложки. Чтобы вернуть встроенную, удалите этот файл.

Подложка включается в меню пунктом `Backplane: ON/OFF`. Она показывается при `Screen: 2x` и `3x`; в режиме `Full` не применяется.

### Формат файла (версия 1, 338117 байт)

| Смещение | Размер | Содержимое |
|---|---|---|
| 0 | 4 | `GBBP` |
| 4 | 1 | версия (1) |
| 5 | 96 | палитра HDMI/VGA: 32 x (R, G, B) |
| 101 | 76800 | HDMI/VGA 2x: 320x240 номеров цветов, построчно |
| 76901 | 76800 | HDMI/VGA 3x |
| 153701 | 96 | палитра TV-SOFT |
| 153797 | 92160 | TV-SOFT 2x: 384x240 |
| 245957 | 92160 | TV-SOFT 3x |

Файл с другим размером или версией прошивка не принимает.
